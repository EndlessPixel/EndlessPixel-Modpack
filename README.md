# EndlessPixel Modpack

## About EndlessPixel

EndlessPixel is a comprehensive Minecraft modpack crafted to elevate your gameplay experience. It integrates a diverse collection of mods, resource packs, and shader packs, catering to different player needs—whether you seek utility enhancements, performance optimization, or immersive visual upgrades, EndlessPixel has you covered.

## System Requirements

Java Version Requirements:

- For Minecraft 1.21.4 ~ 1.21.11: Java 21 or higher

- For Minecraft 26.1+: Java 25 or higher

*For Minecraft 26.1 (Mojang's Pre-release/Snapshot) +: Java 25 or higher (Note: 26.1 is only a pre-release version of Minecraft by Mojang; we have not released any official or beta versions of the modpack for this Minecraft version yet)*

> Important Note: Minecraft 26.1 is currently a pre-release snapshot version (26.1-snapshot-1), and its official version has not been released yet. The above Java version requirement is derived from the official wiki update log (https://zh.minecraft.wiki/w/Java%E7%89%8826.1-snapshot-1) and is for reference only. Pre-release versions are unstable and may have compatibility issues with the modpack. It is recommended that most players use the officially released Minecraft versions (1.21.4 ~ 1.21.11) for a stable gaming experience. If you insist on using the 26.1 pre-release version, please be prepared for potential bugs or functional abnormalities and report issues through the official support channel.

## Runtime Environment

- Client: Optional installation (fully functional as a client-side-only modpack)

- Server: Optional installation

EndlessPixel works seamlessly as a client-side-only modpack—no server installation is required. However, installing it on a server unlocks all features. Some advanced functionalities may not work properly on vanilla servers, but you can still play normally without server-side installation (you will only miss out on certain advanced features).

## Update Policy

EndlessPixel Studio regularly audits and updates the mods, resource packs, and shaders within the modpack. We add new mods based on community feedback and version compatibility, and remove outdated or redundant mods as needed. The modpack typically receives updates every 1–7 days, with occasional extended intervals of 8–14 days. We strive to align closely with the latest Minecraft versions to deliver the optimal experience.
